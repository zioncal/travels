# הטיולים שלי

אתר סטטי (HTML + JavaScript, בלי שלב build) שמתפרסם ב-GitHub Pages.

## מבנה

| קובץ / תיקייה | מה יש בו |
|---|---|
| `index.html` | דף הבית: מפת כל הטיולים + רשימה לפי שנים |
| `trip.html` | דף טיול (`trip.html?t=<id>`): סיפור, מסלול, תמונות, סרטונים |
| `data/trips.js` | **רשימת הטיולים – הקובץ היחיד שעורכים כדי להוסיף טיול** |
| `trips/<id>/photos/` | תמונות מוקטנות (1600px) |
| `trips/<id>/thumbs/` | תמונות ממוזערות (600px) |
| `tools/prepare_photos.py` | מקטין תמונות, מוחק GPS ונתוני מצלמה, מציע מסלול ותאריכים |
| `_incoming/` | תיקייה מקומית לתמונות המקור – **לא עולה ל-GitHub** (ב-.gitignore) |

## הוספת טיול

1. שים את תמונות המקור ב-`_incoming/<id>/` (למשל `_incoming/ein-gedi/`).
2. הרץ: `python tools/prepare_photos.py _incoming/ein-gedi ein-gedi`
3. העתק את מה שהסקריפט מדפיס (נקודה, מסלול, תאריכים, רשימת תמונות) לטיול חדש ב-`data/trips.js`.
4. סרטונים: העלה ל-YouTube כ"לא רשום" (Unlisted) והוסף את המזהה (מה שאחרי `v=`) לשדה `videos`.
5. Commit + Push ב-GitHub Desktop. האתר מתעדכן תוך דקה-שתיים.

## מגבלות GitHub שחשוב לזכור

- אתר GitHub Pages: עד 1GB. בתמונות מוקטנות (כ-0.3MB לתמונה + ממוזערת) זה בערך 2,500 תמונות.
- קובץ בודד: עד 100MB (בהעלאה דרך הדפדפן: 25MB, ועד 100 קבצים בכל העלאה).
- לכן סרטונים נשמרים ב-YouTube ולא כאן.
